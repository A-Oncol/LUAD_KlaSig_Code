# LUAD_KlaSig_Code
This repository contains all the code used in our analyses of LUAD_KlaSig project. It primarily includes the following contents:

- [Spatial data analyses](https://github.com/A-Oncol/LUAD_KlaSig_Code/tree/main/Code/Spatial%20data%20analyses)
- [Single-cell RNA-seq data analyses](https://github.com/A-Oncol/LUAD_KlaSig_Code/tree/main/Code/Single-cell%20RNA-seq%20data%20analyses)
- [H3K18la ChIP-seq data analyses](https://github.com/A-Oncol/LUAD_KlaSig_Code/tree/main/Code/H3K18la%20ChIP-seq)
- [Bulk RNA-seq data analyses](https://github.com/A-Oncol/LUAD_KlaSig_Code/tree/main/Code/Bulk%20RNA-seq%20data%20analyses)
- [Machine learning for LUAD prognosis](https://github.com/A-Oncol/LUAD_KlaSig_Code/tree/main/Code/Machine%20learning%20for%20LUAD%20prognosis)
- [R shiny app](https://github.com/A-Oncol/KlaSig)
